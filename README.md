# Dongfang Wang

Student portfolio: https://oranipost.github.io/

A single-page portfolio covering undergraduate research and the October 2026 GCIC presentation, independent software including Visual Math, channel and market analysis, campus experience, honors, skills, and personal interests.

## Files

- `index.html` contains the full portfolio, with navigation to sections on the same page.
- `student.css` and `student.js` provide the page’s styling and interactions.
- `assets/Dongfang_Wang_Portfolio.pdf` is the complete downloadable portfolio. Keep its menu version query in sync when replacing the PDF.
- Original papers, photographs, and videos remain under `assets/`.
- Earlier page URLs are compatibility redirects handled by `redirect.js`; existing links in shared documents still lead to the relevant section.

## Preview and publish

This is a buildless static website. Run a local HTTP server from this directory to preview it, for example `python3 -m http.server 8765`.

GitHub Pages publishes the `main` branch. After updating and pushing the files, wait for the Pages deployment to complete and check the live page and PDF download.
